# Real Estate AI Agent demo image pack

Upload the nine `.jpg` files and `agent-image-catalog.json` to the same Google Drive folder. Keep the filenames unchanged so n8n can look them up by `asset_key` or filename.

Naming convention:

`demo-{listing-intent}-{property-type}-{view}-{number}.jpg`

These are Pexels stock photos for demos, menus, and generic marketing messages. They are **not real property listings**. The agent must describe them as representative images and must not claim that the pictured property is available, located in India, or owned by the agency.

Before using an image for an actual listing, replace it with photographs of that listing and use a listing-specific filename such as:

`listing-{property-uuid}-apartment-kondapur-exterior-01.jpg`
